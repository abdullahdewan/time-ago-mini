# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-10

### Added - v1.0.0

- Initial release of `time-ago-mini`.
- Core `timeAgo` formatting function.
- Support for `Date` objects, timestamps (numbers), and ISO date strings.
- Formats: "just now", minutes, hours, days, months, and years.
- Zero dependencies.
- TypeScript support with built-in type definitions.
- Both ECMAScript Module (ESM) and CommonJS (CJS) support.
